# Android 壳 ↔ 网页前端 功能对照

> 审计时间：2026-10-27
> 基准：CodeForge-Go 网页端 `web/dist/`（index.html 733 行 + ui.js 7944 行 + app.css 3634 行 + drag.js 81 行，零依赖手写单文件应用；内核源码不在本仓库，见 AGENTS.md 第 1 节边界）
> 对象：`app/src/main/java/com/hxy/codeforge/`（Kotlin + Compose）
>
> 核实方式：逐项 grep Android 侧关键词 + 读实现，未核实的标「待确认」。

## 一、结论

**网页端 8 大类功能中，Android 已覆盖 6 类；缺口集中在「工作区/项目管理」「消息流里的三类交互」「外观个性化」。**

最严重的两个缺口：

1. **没有工作区（项目）概念** —— 网页端侧栏按工作区分组，会话挂在项目下；Android 是平铺列表。这导致：新建项目、项目重命名/归档/删除、在指定项目下建会话、项目折叠全部缺失。
2. **没有多会话并发分桶** —— 网页端按 `session_id` 分桶（`runningSessions` / `streams` / `frameIsMine`），切走再切回能补齐；Android 没有这套机制，后台会话的流式帧可能画进当前视图。

## 四、已对齐（确认实现）

- **消息气泡**：用户/助手/思考折叠/通知/警告/错误/工具卡/审批条/子智能体卡/重试横幅
- **流式渲染**：增量重绘、思考流式、自动跟随、用户上滚不被拽回
- **Markdown**：代码块/表格（三向对齐）/引用/分隔线/粗斜体/链接/行内码
- **公式**：行内 + 块级，自研 LaTeX 子集（离线，不依赖 CDN）
- **输入区**：多行、附件（图片/文件）、@ 提及技能与内置插件、四态主按钮
- **模型**：切换、思考强度、供应商增删改、探测模型、密钥来源（env/明文）
- **会话**：新建/切换/重命名/删除/归档/恢复/历史回放
- **工具**：卡片文案映射、diff 全屏查看器、审批 HITL、子智能体进度
- **设置**：生成轮数、重试策略、压缩、子智能体、通知、MCP、技能、记忆、内置插件
- **其他**：任务清单、上下文用量、检查点回滚

## 五、建议排期

1. **P0-4 多会话并发分桶** —— 数据正确性问题，优先于所有 UI 缺口。现在的实现下，切会话时后台帧可能污染当前视图。
2. **P0-1~3 工作区/项目** —— 需要改 `SessionPane` 数据源（`ChatUiState.sessions` → 按 workspace 分组）、加新建项目弹窗、加项目行菜单。内核侧 `/api/workspaces` 已就绪，只需前端接线。
3. **P1-5 探索分组** —— 纯 UI，但需要「连续只读工具」的判定（网页端靠 DOM 相邻性，Compose 里要改成一个消息内的聚合模型）。
4. **P2 外观四项** —— 独立、低风险，可并行。

## 六、需要澄清的口径

- **顶栏**：网页桌面端**没有顶栏**（设置/模型/权限分散在侧栏底与输入卡底）。Android 的顶栏属新增，不算偏差，但意味着网页端的「无顶栏」布局不该作为对齐目标。
- **发送键语义**：网页是四态「打断 / 转向 / 发送 / 变暗」；Android 的四态是「聆听中 / 停止 / 发送 / 待听写」（含语音）。两者语义不同，需确认是否要合并。
- **思考强度**：网页按协议分键记忆（`cf_thinking_steps` / `cf_thinking_range`），Android 用 `AppSettings.thinkingLevel` 单一索引，切模型协议不同时不会回落默认档。

**真正要补的两条**：

1. **`/api/termux/tools`** —— Android 的 `EnvPackagesSection.kt` **没有任何 API 调用**（grep 0 命中），
   说明它是纯本地/静态实现。前端那套「检测到 Termux 且没装 termux-tools → 弹窗 → 点安装 →
   `pkg install` → 轮询状态 → 已安装 ✓ / 跳过 / 不再提示」完全缺失。
2. **`/api/tree`** —— Android 没有工作区文件浏览。选工作区靠 SAF，但**看不到工作区里有什么**。

其余 6 条 Android 用别的途径实现了（SAF 选文件、本地复制附件、`/api/models/save` 循环），
语义等价，不算缺口。

### 模型编辑器字段差

- **RPM**（每分钟请求上限）
